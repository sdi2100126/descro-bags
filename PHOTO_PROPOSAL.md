PHOTO PROPOSAL FOR DESCRO BAG DESIGNS
======================================

This document proposes specific images from the public/media/ folders to use as main and additional images for each bag design.
The actual wiring into lib/products.ts would be done in a separate task.

For each design, we list the available images, then propose:
- One main image (clear product-forward shot, well-lit, simple background)
- Up to three additional images (detail/angle shots and possibly one lifestyle/worn shot)

We note the resolution and approximate file size (from `ls -lh`) to flag unusually large images that may need compression.

Note: All images are JPEGs. File sizes are approximate.
